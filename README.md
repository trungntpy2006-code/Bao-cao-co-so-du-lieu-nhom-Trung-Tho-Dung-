Hướng Dẫn Cài Đặt & Chạy Dự Án mini_netflixDự án gồm 1 file Python để sinh dữ liệu test ra file .csv và 3 file SQL để tạo cấu trúc bảng, nạp dữ liệu hàng loạt, tạo trigger/view và chạy truy vấn kiểm thử.1. Yêu cầu môi trườngMySQL Server 8.0+ và MySQL Workbench.Python 3.x (dùng thư viện chuẩn như csv, random, datetime...).Bật LOCAL INFILE để MySQL Workbench nạp file CSV từ máy local:Trong MySQL Workbench: Vào Database -> Manage Connections... -> chọn connection -> tab Advanced -> thêm OPT_LOCAL_INFILE=1 vào mục Others: -> Reconnect to Server.Trên MySQL Server: Chạy lệnh:SQLSET GLOBAL local_infile = 1;
SHOW VARIABLES LIKE 'local_infile'; -- Đảm bảo giá trị là ON
2. Cấu trúc file trong dự án (ví dụ)01_create_tables_and_sample_data.sql (hoặc file tạo schema/bảng đầu tiên): Tạo database mini_netflix, các bảng, ràng buộc khóa chính/khóa ngoại/check và dữ liệu danh mục mặc định (SUBSCRIPTION_TIER).   <script_sinh_du_lieu>.py: Sinh dữ liệu mẫu ra thư mục csv_output/ (mặc định có thể chỉnh số lượng user/dòng xem).<file_load_csv>.sql: Xóa dữ liệu cũ (nếu cần) và nạp toàn bộ file .csv vào các bảng theo đúng thứ tự khóa ngoại bằng LOAD DATA LOCAL INFILE.03_triggers_views_and_queries.sql (hoặc file trigger/view/truy vấn): Tạo trigger, view và các câu truy vấn kiểm tra/nâng cao.3. Thứ tự chạy chi tiếtBước 1: Tạo database và bảngMở file SQL tạo bảng (01_create_tables_and_sample_data.sql) trong MySQL Workbench.   Chạy toàn bộ file để tạo schema mini_netflix, các bảng và dữ liệu gói cước ban đầu.   Bước 2: Sinh dữ liệu CSV bằng PythonMở file .py sinh dữ liệu, kiểm tra/chỉnh thông số nếu muốn (ví dụ số lượng users hoặc số lượt xem/lưu tối đa) và đường dẫn xuất thư mục CSV (ví dụ csv_output/).Chạy file Python:Bashpython ten_file_sinh_data.py
Kiểm tra thư mục xuất ra đã có đủ các file .csv tương ứng với các bảng (tv_series.csv, content.csv, movie.csv, episode.csv, content_genre.csv, user.csv, profile.csv, watches.csv, saves_to.csv).Bước 3: Nạp dữ liệu CSV vào MySQLMở file SQL nạp dữ liệu.Sửa đường dẫn thư mục CSV trong file SQL cho đúng với máy của bạn (nhớ dùng dấu / hoặc \\, ví dụ D:/.../csv_output/).Chạy file SQL để nạp dữ liệu theo đúng thứ tự bảng cha -> bảng con.Lưu ý: Nếu nạp bảng lớn như WATCHES, nên tạm tắt trigger INSERT (nếu có) và bật lại ngay sau khi nạp để chạy nhanh hơn.Bước 4: Tạo Trigger, View và chạy truy vấn kiểm traMở file SQL chứa trigger, view và truy vấn.Chạy phần tạo Trigger và View trước.Chạy các câu lệnh SELECT kiểm tra số dòng từng bảng, dữ liệu view và các truy vấn nâng cao để xác nhận hệ thống hoạt động đúng.
